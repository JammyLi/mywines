────────────────────────────────────────────
一、安裝前準備
────────────────────────────────────────────

1. 選一台「伺服器電腦」安裝：Windows 10 或 11（64 位元），
   上班時間都開著。其他電腦和手機不需要安裝，用瀏覽器連線即可。
2. 這台電腦的「睡眠」請設成「永不」：
   設定 › 系統 › 電源 › 螢幕與睡眠 › 接上電源時，讓裝置進入睡眠 ›「永不」。
3. 建議請管理路由器的人，幫這台電腦設定「固定 IP（DHCP 保留）」，
   其他電腦和手機的網址才不會變。


────────────────────────────────────────────
二、第一次安裝
────────────────────────────────────────────

1. 把壓縮檔下載到「下載」資料夾。
2. 在壓縮檔上按右鍵 ›「解壓縮全部…」›「解壓縮」。
   （一定要先解壓縮，不要在壓縮檔裡直接執行。）
3. 在解壓縮出來的資料夾裡，雙擊 MyWines-Setup-{{VERSION}}.exe。
4. 如果出現「Windows 已保護您的電腦」：
   按「其他資訊」›「仍要執行」。
5. 出現「是否允許此應用程式變更您的裝置？」：按「是」。
6. 一路按「下一步」，最後按「完成」。
   系統會自動開啟瀏覽器，進入登入畫面。
7. 用初始帳號登入：
     登入名稱：jammy
     密碼　　：123456
8. 登入後請立刻：
   ‧ 到「設定 › 使用者」修改初始密碼，並為每位同事建立帳號。
   ‧ 到「設定 › 公司資料」填公司名稱、上傳 Logo。
   ‧ 到「設定 › 儲位管理」建立酒窖、分儲空間、架子（也可以從 Excel 匯入）。

安裝完成後：
  ‧ 桌面會有「酒窖庫存」捷徑，在這台電腦開啟系統。
  ‧ 開始功能表 › MyWines：
      酒窖庫存　　　　　開啟系統
      手機設定　　　　　顯示 QR Code，給手機掃描
      連線位址　　　　　顯示其他電腦要輸入的網址
      資料與備份資料夾　開啟資料存放位置
      解除安裝
  ‧ 系統會在開機時自動執行，不需要登入 Windows，也不用開任何視窗。

其他電腦：
  在這台電腦開「開始 › MyWines › 連線位址」，看到類似
  http://192.168.1.23:3000 的網址，在其他電腦的瀏覽器輸入即可。

手機（iPhone / Android）：
  在這台電腦開「開始 › MyWines › 手機設定」，用手機相機掃 QR Code，
  照畫面安裝憑證，再「加入主畫面」。手機需連同一個 Wi-Fi。


────────────────────────────────────────────
三、升級（已經安裝過）
────────────────────────────────────────────

不需要先解除安裝，直接安裝新版即可，資料不會受影響。

1.（建議）先備份資料：
   開「開始 › MyWines › 資料與備份資料夾」，
   把整個資料夾（C:\ProgramData\MyWines）複製到隨身碟或其他位置。
2. 把新版壓縮檔下載到「下載」資料夾，右鍵 ›「解壓縮全部…」。
3. 雙擊 MyWines-Setup-{{VERSION}}.exe，出現提示時按「其他資訊 › 仍要執行」、「是」。
4. 安裝位置會自動帶入原本的位置，請不要修改，一路按「下一步」›「完成」。
   安裝程式會自動：停止系統 → 更換程式 → 重新啟動，約 1 分鐘。
5. 開啟系統，確認畫面左下角顯示「版本 v{{VERSION}}」。
6. 其他電腦或手機如果左下角出現「有新版，按此更新」，按一下即可；
   或直接重新整理網頁。手機不需要重新安裝憑證。


────────────────────────────────────────────
四、資料放在哪裡
────────────────────────────────────────────

  程式：C:\Program Files\MyWines
  資料：C:\ProgramData\MyWines（資料庫、照片、憑證、備份、紀錄）

  ‧ 升級和解除安裝都「不會」刪除資料。重新安裝後會自動接續使用。
  ‧ 資料只存在這台電腦，不會上傳到網路。請定期備份上面的資料夾。


────────────────────────────────────────────
五、常見問題
────────────────────────────────────────────

Q：其他電腦或手機打不開？
A：確認和伺服器電腦連同一個網路；網址的 IP 用「連線位址」顯示的那一個
   （通常是 192.168 開頭）。伺服器電腦要開機、不能睡眠。

Q：伺服器電腦本身也打不開？
A：開始功能表搜尋「服務」，找到「MyWines Wine Inventory」，
   按右鍵 ›「重新啟動」。

Q：忘記密碼？
A：請其他同事登入後，到「設定 › 使用者」幫你重設。

Q：要回報問題？
A：請先告訴我們畫面左下角的版本號。

更詳細的操作請看「使用手冊.pdf」。
