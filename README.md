# 酒類庫存管理系統

辦公室內網使用。資料只存在這台電腦的 `data/mywines.db`，不會上傳到外部。

## 第一次安裝

需要 Node.js 20 以上（https://nodejs.org 下載 LTS 版）。在這個資料夾打開「終端機」：

```
npm install
npm run build
npm start
```

畫面會顯示網址，例如：

```
這台電腦：http://localhost:3000
其他電腦（同一 Wi-Fi）：http://192.168.1.23:3000
手機（可掃描、離線）：https://192.168.1.23:3443
手機第一次使用，先開：http://192.168.1.23:3000/setup
```

Mac 第一次啟動時如果跳出「是否允許 node 接受連入連線」，請按「允許」，其他電腦和手機才連得到。

## 手機設定（每支手機一次）

手機的相機掃描和離線功能需要加密連線（HTTPS）。系統第一次啟動時會在 `data/tls/` 自己產生一張只在公司內網使用的憑證。

1. 手機連公司 Wi-Fi，開 `http://（這台電腦的 IP）:3000/setup`（電腦上開這一頁，用手機相機掃畫面上的 QR Code 最快）。
2. 照頁面步驟下載並安裝憑證：
   - iPhone：用 Safari 下載 → 設定 › 已下載描述檔 › 安裝 → 設定 › 一般 › 關於本機 › 憑證信任設定，打開「MyWines Local CA」。
   - Android：用 Chrome 下載 → 設定 › 安全性 › 安裝憑證 › CA 憑證。
3. 開 `https://（IP）:3443/m` 登入，再「加入主畫面」。之後從主畫面圖示開啟。

建議請網管把這台電腦設成固定 IP；IP 變了系統會自動換新憑證，手機不必重裝，只要用新網址。

## 手機離線怎麼運作

- 在公司 Wi-Fi 開啟時，手機會下載一份查詢用的資料（不含採購價格、酒商、客戶與設定）。
- 在酒窖沒有訊號時，可以掃描查詢、移動酒瓶或整箱、標記破損、掃描建立清單、盤點。
- 回到公司 Wi-Fi 會自動上傳。如果同一瓶酒在你離線時被別人移動過，手機會顯示「同步衝突」，由你選擇保留哪一個；兩種選擇都會記入異動紀錄。
- 登出時會清除手機上的資料（還有沒同步的操作時會先提醒）。

## 查價助手（Wine-Searcher）

- 系統不儲存 Wine-Searcher 帳號密碼，也不自動抓取網頁；由你在自己的瀏覽器查價。
- 第一次：到「設定 › 查價設定」，把「查價助手」按鈕拖到瀏覽器書籤列。
- 從清單按「更新市場價格」：系統一款一款開啟查詢頁；看到價格後按書籤「查價助手」，價格與網址會送回系統，確認後採用。讀不到時直接輸入。
- 每款之間隨機等 10–20 秒，每小時最多 20 款、每天 100 款（可在設定調整）。
- 變動超過 ±20% 會要求再次確認。
- 也可以在「市場價格」頁直接在列表輸入，或下載 Excel 範本填好後上傳。

初始帳號：登入名稱 `jammy`，密碼 `123456`（請在第二階段的「設定 › 使用者」改掉）。

## 匯入 Excel

登入後到「匯入」，把 `sample_data/Inventory.xlsx` 拖進去 → 檢查合併建議與注意事項 → 確認匯入。

- 酒窖 = 酒窖（Cellar）、位置 = 分儲空間（Locker）、編號 = 箱號（Case）
- Excel 沒有架子，酒箱先放在各分儲空間的「未指定」架子
- 位置含「?」的酒箱標記為「位置待確認」
- 種類代碼 S 先匯入為「待對應（S）」
- 安迪酒藏→安迪、吉興→吉星 已預先勾選合併

也可以用指令匯入：`npm run import -- sample_data/Inventory.xlsx`

## 重新開始（清空資料）

```
npm run reset-db
```

會先把舊資料庫備份到 `data/backup/`。

## 訂單怎麼運作

1. 從「我的清單」按「轉成訂單」、從「庫存搜尋」按「建立訂單」，或在「訂單」按「＋ 建立訂單」，選客戶。
2. 填數量、單價（未稅，每瓶）、折扣。單價預設帶入這位客戶上次的成交價，沒有的話帶建議售價；折扣帶入客戶預設折扣。畫面下方會顯示採購成本與毛利（不印在客戶版）。
3. 按「確認訂單」：系統挑好瓶號並「保留」，其他訂單不能再用這些瓶。要修改就「改回草稿」。
4. 印「揀貨單」去酒窖拿酒，再到「出貨」掃描實際拿出的瓶號或箱號。拿同款的其他瓶也可以，系統會自動換掉保留的瓶號。
5. 確認出貨後扣庫存，全部記入異動紀錄（類別「銷售」）。
6. 「客戶版 PDF」依客戶偏好語言列印，含公司抬頭、營業稅、運費與總金額。不開電子發票。

## 標籤印表機

建議 Brother QL-820NWB，接辦公室網路。按「列印」後在瀏覽器的列印視窗選這台印表機：
- 酒瓶小標：29 × 62 mm 預切標籤
- 酒箱、分儲空間、架子：62 mm 連續標籤（100 mm 長）
- 邊界選「無」。要存 PDF 就選「另存為 PDF」。

印好後按「已印好，標記為已列印」，系統會記錄哪些瓶號已貼標。

## 資料與備份

所有資料都在 `data/` 資料夾（資料庫 `mywines.db`、照片 `photos/`、HTTPS 憑證 `tls/`）。備份就是把整個 `data/` 資料夾複製到隨身碟或 NAS。

## 開發

- `npm run dev`：前端熱更新（另開一個視窗跑 `npm start` 提供 API）
- `npm test`：自動測試
- 技術：Node + Express 5 + SQLite（better-sqlite3）＋ React 19 + Vite
